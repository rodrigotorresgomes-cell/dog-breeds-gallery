# Interactive CSS Gallery 🐕

An academic project developed for the Multimedia Tools and Applications class. This frontend project features a responsive image grid with interactive hover effects that reveal detailed descriptions upon user interaction.

##  Tech Stack
* **HTML5:** Semantic structure and internal anchor navigation.
* **CSS3 & SASS (SCSS):** Advanced styling using modular SASS architecture (abstracts, base, layout) for maintainable and scalable code.
* **Vanilla JavaScript:** Basic DOM interactions.

##  Key Highlights
* **SCSS Architecture:** Codebase structured using modern CSS preprocessor best practices.
* **Interactive UI:** Engaging hover effects and transitions built for a dynamic user experience.
* **Anchor Scrolling:** Functional internal navigation for seamless browsing.

##  How to run locally
1. Clone this repository or download the ZIP file.
2. Open the `index.html` file in your preferred web browser. No local server is required.
